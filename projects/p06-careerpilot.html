⚡ Core Features

8 Modules
📄
Resume Import & Extraction
Upload PDF, DOCX, TXT or paste text. Drag & drop supported. AI extracts name, email, phone, LinkedIn, GitHub, skills, experience, education, certs, projects — never fabricates.
🔍
AI Resume Analysis
7-dimension scoring: ATS Compatibility, Skills Coverage, Quantification, Keyword Coverage, Formatting, Experience Relevance, Achievement Strength. Each recommendation explains why and how to fix.
✨
ATS-Optimized Remaster
8 templates: Modern, Conservative, Technical, Data Analyst, Finance, BA, Data Science, MIS. One page or two page. No graphics, no tables, strong action verbs, export TXT.
🔎
Multi-Platform Job Search
Modular adapter architecture for LinkedIn, Naukri, Indeed. Filters: keyword, location, work mode, employment type, experience level. Normalised job format.
🎯
AI Job Matching (1-100)
Every job scored against your resume: skill overlap, title similarity, experience relevance, location preference, education match. Reasons displayed per match.
✍️
Cover Letter Generator
Company-specific, role-specific cover letters generated from YOUR resume only. No fabricated experience. Copy or edit before sending.
🛡️
User Control & Ethics
Never bypasses CAPTCHA or MFA. Never captures passwords. Pauses for human verification. User approves every final submission. Ethics-first design.
📋
Application Tracker
Full pipeline tracking: Saved → Applied → Interview → Offer → Rejected. Notes per application, status updates, dashboard stats, CSV export.

📡 REST API Endpoints

15 Endpoints
MethodEndpointDescription
POST/api/resume/uploadParse & AI-analyze resume text
GET/api/resume/:idRetrieve full resume + analysis data
POST/api/resume/:id/remasterGenerate ATS-optimized master resume

🛡️ Ethics & Privacy

Non-Negotiable
🚫
No Fabrication
AI only uses information extracted directly from your resume. Zero invented qualifications, experience, or achievements.
🔐
No Password Capture
Platform authentication always occurs via the official login flow. CareerPilot AI never sees your credentials.
🤖
No CAPTCHA Bypass
The system pauses and requests user action for CAPTCHA, MFA, and human verification requirements.
✅
User Controls Submission
Every final application submission requires explicit user review and approval. AI assists, human decides.

🚀 How to Run

Local Setup
# Clone the repository
git clone https://github.com/akash-pathak-scientist/careerpilot-ai
cd careerpilot-ai

# Install dependencies
pip install flask flask-cors

# Start the server
cd backend && python app.py

# Open in browser
http://localhost:5050
