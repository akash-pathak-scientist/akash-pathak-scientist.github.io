🧠 Product-Image Classifier (CNN)

Flipkart-style catalogue auto-categorisation into Apparel / Electronics / Home — MobileNetV3-Small (1.52M params) fine-tuned on 20,754 real product images from the public Amazon Reviews 2023 corpus (Hou et al., 2024). Fully reproducible: stream-sampled metadata → image fetch → stratified split → train → confusion-matrix & sub-category error analysis. One-click Google Colab notebook included.

📈 Training Curves

Loss & accuracy vs epoch
Two stages: (1) 160px warm-up, AdamW head 7e-4 / trunk 1.4e-4; (2) 224px fine-tune, AdamW 2.5e-4 cosine, label smoothing 0.05, batch 24, early stop. Full provenance: reports/TRAINING_LOG_NOTE.md in the repo.

🧪 Pipeline

100% reproducible
📥 Data
  • Stream-samples public JSONL via HTTP range requests (no multi-GB download)
  • Parallel fetch + Pillow validation + EXIF fix + SHA-1 content dedup
  • 165 dead URLs & 81 duplicate images dropped automatically
🏋️ Training
  • torchvision transforms: RandomResizedCrop, flip, rotation, colour jitter
  • AdamW + cosine annealing + label smoothing 0.05
  • Early stopping on val accuracy; best checkpoint tracked automatically
📓 Reproduce in Colab
  • notebooks/product_image_classifier_colab.ipynb — Runtime → T4 GPU → Run all
  • Downloads dataset.zip from the v1.0.0 release (images + splits + metadata)
  • Trains both models; prints the same tables & confusion matrix
🔮 Single-image inference
  • python -m src.predict path/to/product.jpg → ranked class probabilities
  • Checkpoint stores arch, classes, img size & normalisation stats
